# Деплой на Railway

## ⚠️ КРИТИЧЕСКАЯ ОШИБКА: Регулярное выражение CORS

**Проблема:** В старой версии было `r"/api/*"` — это **неправильное** регулярное выражение!
- В Python `*` означает «повторение предыдущего символа»
- Выражение `r"/api/*"` ищет `/api` + любое количество слешей
- Оно **НЕ подходит** для путей типа `/api/auth/login`

**Решение:** Исправлено на `r"/*"` — теперь CORS работает для всех путей.

## Что исправлено в app.py

### 1. CORS настроен правильно
- **Исправлено регулярное выражение**: `r"/*"` вместо `r"/api/*"`
- Если `CORS_ORIGINS` не задана или равна `*` → разрешены все источники
- Если задана → убираются пробелы и парсится список через запятую

### 2. Инициализация БД перенесена в create_app()
- `db.create_all()` и создание владельца теперь выполняются **внутри фабрики**
- Это работает и под Gunicorn, и при прямом запуске
- Владелец и боксы создаются автоматически при первом запуске

### 3. Порт и хост для облачных платформ
- Используется переменная окружения `PORT` (Railway её автоматически задаёт)
- `host='0.0.0.0'` позволяет принимать внешние подключения
- `debug` отключается в production (если `FLASK_ENV=production`)

## Настройка переменных окружения в Railway

Перейдите в настройки проекта → Variables и добавьте:

```bash
# Обязательные
DATABASE_URL=postgresql://user:password@host:port/dbname  # Railway автоматически создаст при подключении PostgreSQL
JWT_SECRET=ваш-очень-секретный-ключ-минимум-32-символа

# Опциональные
CORS_ORIGINS=https://crm-car-wash-api.vercel.app  # БЕЗ слеша в конце!
DEFAULT_OWNER_LOGIN=owner
DEFAULT_OWNER_PASSWORD=owner123
FLASK_ENV=production
```

**Важно:**
- `DATABASE_URL` Railway создаст автоматически, когда вы добавите PostgreSQL сервис
- `CORS_ORIGINS` — укажите точный адрес фронтенда без слеша в конце
- Если не указать `CORS_ORIGINS`, будет работать `*` (все источники)

## Команда запуска (Start Command)

В настройках Railway укажите:

```bash
gunicorn app:app
```

Или если нужно указать количество воркеров:

```bash
gunicorn app:app --workers 2 --timeout 120
```

## Troubleshooting

### ⚠️ База данных стирается при каждом перезапуске
**Причина:** Переменная `FORCE_RECREATE_DB=true` в Railway
**Решение:** 
1. Railway → Variables
2. Найдите и **удалите** `FORCE_RECREATE_DB`
3. Перезапустите сервис

### CORS ошибка
- Проверьте, что `CORS_ORIGINS` содержит **точный** адрес фронтенда
- Убедитесь, что нет лишних пробелов
- Временно удалите `CORS_ORIGINS` из переменных (будет работать `*`)

### Владелец не создался
- Теперь это невозможно — инициализация происходит в `create_app()`
- Проверьте логи Railway на наличие сообщения о создании владельца

### 500 ошибка при старте
- Проверьте, что `DATABASE_URL` правильный
- Убедитесь, что PostgreSQL сервис подключен в Railway
- Посмотрите логи Railway на наличие Python traceback

### Порт не работает
- Railway автоматически задаёт `PORT` — не нужно его указывать вручную
- Убедитесь, что используете `gunicorn app:app` без указания порта
